# MonetAcademy

Plataforma educativa para aprender finanzas personales de forma sencilla y práctica: ahorro, presupuesto, deudas y metas.

## Contenido
- Temas de finanzas personales
- Tutorías paso a paso
- Herramientas interactivas: presupuesto 50/30/20, meta de ahorro e interés compuesto
- Experiencias de ejemplo y formulario de contacto

## Estructura
```
monetacademy/
├── index.html
├── css/styles.css
└── js/main.js
```

## Uso
Abre `index.html` en el navegador.
